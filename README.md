# CLAM Boats — website

English Challenge website for **CLAM**, a simulated boat company (SeaTech company project, November 2026). *Keep CLAM.*

- `index.html`: the whole site (single page, inline CSS/JS, English subtitles built in)
- `*.jpg`, `*.png`, `*.mp4`: logo, gallery illustrations, brand clip and French ad spot

Served with GitHub Pages from the `main` branch root. This is a student simulation: the company, contact details and the EU partnership are fictional.
